# 사람 검토용 보고 — 수리사 모바일 작업 흐름

- 작성일: 2026-08-13
- 대상: 수리사·복지관·제품 검토자

수리사 화면이 배정 작업을 보는 데서 끝나지 않고 일정 확정, 작업 시작, 비용 제출, 복지관 검증 대기까지 이어지도록 바뀌었다. 각 화면에는 현재 해야 할 한 가지 행동만 크게 표시한다.

개인 연락처와 지원금 잔액은 내려받지 않는다. 현장에서는 공개 고객코드와 기기 공개코드를 대조한다. 제출 버튼을 눌러도 “수리 완료”라고 표시하지 않으며 복지관 검증이 남았음을 분명히 안내한다.

## 사람이 실기기에서 확인할 항목

- Android에서 키보드가 비용 입력·제출 버튼을 가리지 않는가
- iPhone에서 뒤로가기와 화면 스크롤이 자연스러운가
- TalkBack·VoiceOver가 단계, 상태, 버튼을 올바른 순서로 읽는가
- 공개코드만으로 실제 현장 기기·대상자를 혼동 없이 확인 가능한가
