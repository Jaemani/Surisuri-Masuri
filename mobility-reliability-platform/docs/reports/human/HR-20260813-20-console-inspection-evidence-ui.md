# HR-20260813-20 — 복지관 예방점검 설명 화면 점검

- 발행일: 2026-08-13
- 상태: generated / 사람 검토 대기
- 대상 독자: 프로젝트 운영자·복지관 화면 검토자
- 로드맵 게이트: R10 Device Timeline & Reliability

## 현재 실제 상태

복지관 콘솔 예방점검 화면이 근거 중심 workspace로 바뀌었다. 담당자는 한 항목을 선택해 현재 확인된 사실, 아직 필요한 정보, 이어서 할 운영 조치를 볼 수 있다. 데이터가 부족한 예시는 `판단 유보`로 표시되며 고장 확률이나 신뢰도 숫자를 만들지 않는다.

## 운영 검토 요청

- 이용자 접수, 센터 검증 이력, 운영 일정의 구분이 현장 업무와 맞는지
- `판단 유보` 시 필요한 데이터와 다음 조치가 충분히 명확한지
- 예방점검 화면에서 수리 요청으로 이어지는 흐름이 자연스러운지

## 한계

현재 화면과 값은 모두 합성 데모다. 실제 기관 사용자 테스트, 접근성 보조기기 검증, 실제 수리·점검·거리 데이터, field metric, production 배포를 뜻하지 않는다. 회의 일시·참석자·사진·지출은 사람 확인 전 기록하지 않는다.
