# 사람 검토용 보고 — PyTorch 최소 후보와 배포 유보

- 작성일: 2026-08-13
- 리포트 ID: `HR-20260813-17`
- 대상: 기술·성과 검토자

기존 합성 데이터와 고정 split으로 작은 PyTorch 모델을 직접 학습·평가하는 재현 harness를 만들었다. 모델 입력에는 원시 좌표가 없고, 학습에 test 데이터를 섞지 않으며 model state hash까지 남긴다.

하지만 합성 데이터는 규칙 기준선이 이미 완벽하게 맞히도록 분리돼 있다. 따라서 이 모델의 숫자는 현장 성능이나 AI 우월성을 뜻하지 않는다. 실제 동의 데이터의 독립 평가셋이 생기기 전까지 ONNX와 모바일 배포를 유보한다.

이 단계의 성과는 모델 성능이 아니라 PyTorch CPU 환경, frozen split, deterministic training, rules 비교, 배포 유보 판단을 코드와 테스트로 남긴 것이다.
