# 사람 검토용 보고 — 수리사 상태 변경 보안 보강

- 작성일: 2026-08-13
- 검토 대상: 개발·기관 운영 담당자

## 요약

수리사 앱을 실제 command에 연결하기 전 서버 계약을 점검해, 정상 상태 변경 요청에 배정·지원금 필드를 함께 보내면 권위 데이터가 변경될 수 있는 문제를 발견하고 차단했다.

일정 확정은 이제 실제 일정시각을 저장한다. 작업 제출시각은 휴대폰이 보내지 않고 서버가 기록한다. 수리사는 일정 확정, 작업 시작, 비용 제출만 수행하며 복지관의 지원금 검증이나 완료 처리를 대신할 수 없다.

## 사람이 확인할 사항

- 일정 허용 범위인 현재 15분 전~180일 후가 현장 운영에 적절한가
- 무상 수리를 0원으로 받을지, 별도 사유 코드로 설계할지
- 다음 단계의 구조화된 수리 항목에 어떤 분류가 필요한가

## 증빙 범위

로컬 unit/typecheck와 Firebase Emulator 시나리오를 통과했다. 실제 Firebase Auth/App Check 연결, 배포, 현장 수리사 사용성은 아직 검증하지 않았다.
