# 사람 검토용 보고 — 수리사 작업 목록 데이터

- 작성일: 2026-08-13
- 대상: 수리사 모바일·기관 운영 담당자

수리사에게 자신에게 배정된 작업만 보여주는 서버 projection을 보강했다. 화면은 공개 고객코드, 기기 공개코드와 모델, 증상 분류, 일정, 현재 단계만 사용하며 지원금 잔액이나 개인 연락처를 받지 않는다.

상태별 가능한 동작도 서버가 내려준다. 배정 상태에서는 일정 확정, 일정 상태에서는 작업 시작, 진행 중에는 비용 제출만 가능하다. 제출 뒤에는 복지관 검증을 기다리는 읽기 상태가 된다.
