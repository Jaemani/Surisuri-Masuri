수리사 앱이 서버에 보낼 수 있는 동작을 일정 확정, 작업 시작, 비용 제출로 제한했다. 수리소 배정이나 지원금 판정 필드는 모바일 API에 존재하지 않는다.

다음 화면 구현에서는 이 adapter를 사용하되, 비용만 받는 현재 계약을 실제 수리 항목 보고서처럼 과장하지 않는다.
