### EVD-20260811-001 — 모바일 upload disposition과 v4 state integrity

- 생성: 2026-08-11 KST / 작성자: Codex
- 환경·데이터: `local` / `synthetic`·`test fixture` only
- 출처: source commit [`a9a57cc`](https://github.com/Jaemani/Surisuri-Masuri/commit/a9a57ccb424ad6b6b66983e201436990d426e970), WSL2 local verification

- 상태: `generated` — 사람 검토 대기

#### 확인한 범위

- Upload lease의 bounded FIFO/integrity scan과 첫 100개가 미래 상태일 때의 global due
  fallback 후보 재검증.
- Exact stored body digest, canonical retry/lease/attempt metadata, binding count와
  `position=0..sample_count-1` 연속성의 fail-closed 경계.
- ACK·hold·retry disposition이 parent upload batch와 bound outbox child를 하나의
  exclusive transaction에서 전이하는지 확인.
- Schema v4 migration이 writer lock 뒤 `user_version`을 읽고 invalid terminal state,
  body/binding 및 position gap/out-of-range/fractional을 모든 batch 상태에서 거부하는지
  확인.
- BEGIN/ROLLBACK lifecycle, COMMIT 응답 유실 뒤 fresh query-only correlation의
  `committed`/`not_committed`/`unverifiable` 결과를 확인.

#### 증명하는 것

이 source와 synthetic/test fixture 범위에서 mobile local upload state의 atomic
disposition, migration integrity, bounded due fallback과 commit uncertainty에 대한
fail-closed 결과를 재현한다.
