# ADR-0067 — 승인된 제품명·로고 원본 고정

- 상태: accepted
- 결정일: 2026-08-20
- 범위: 모바일 앱·복지관 콘솔·발표 화면의 제품 식별

## 문제

신규 코드베이스의 외부 제품명이 미정이라는 과거 경계 때문에 콘솔에 승인되지 않은 placeholder `모두의 이동`이 들어갔다. 이는 사용자가 제공한 현재 제품명·로고와 다르며 발표 화면에 사용할 수 없다.

## 결정

- 현재 UI 제품명은 `수리수리마수리`로 고정한다.
- 승인 원본은 `attached/sources/brand/logo-original.png`이며 신규 저장소에는 byte-identical 사본만 둔다.
- 원본의 흰 배경을 제거하거나 형태를 추정 편집하지 않는다. 필요한 화면에서는 overflow crop으로 외곽 흰 여백만 가린다.
- 콘솔은 승인 로고의 심볼 crop과 `수리수리마수리 / 복지관 운영 콘솔`을 표시한다.
- 모바일 Expo display name도 `수리수리마수리`로 표시한다.
- `모두의 이동`과 다른 임의 제품명은 제품 코드에 허용하지 않고 Playwright가 부재를 검사한다.

## 경계

이 결정은 사용자가 제공한 현재 제품 UI 식별을 반영한다. 상표 출원·외부 법률 검토 완료를 주장하지 않으며, 과거 기업 소유 코드·UI·배포 런타임을 재사용하는 결정도 아니다.
